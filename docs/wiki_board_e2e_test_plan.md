# 위키/게시판 E2E 테스트 계획

## 1. 테스트 개요

- **테스트 대상**: 위키(Wiki), 게시판(Posts/Board) 기능
- **테스트 환경**: localhost:8000 (백엔드 API)
- **인증 방식**: JWT 토큰 (admin 계정)
- **테스트 시간**: 2026-07-22

---

## 2. 테스트 항목

### 2.1 위키(Wiki) 기능

| 테스트 ID | 테스트 항목 | API 엔드포인트 | 예상 결과 |
|-----------|------------|---------------|----------|
| W-001 | 프로젝트 위키 목록 조회 | `GET /api/wiki?project_id={id}` | 200 OK, 위키 목록 반환 |
| W-002 | 새 위키 페이지 생성 | `POST /api/wiki` | 201 Created, 페이지 ID 반환 |
| W-003 | 위키 페이지 수정 | `PUT /api/wiki/{id}` | 200 OK |
| W-004 | 위키 페이지 삭제 | `DELETE /api/wiki/{id}` | 200 OK |
| W-005 | 위키 버전 이력 조회 | `GET /api/wiki/{id}/versions` | 200 OK, 버전 목록 반환 |
| W-006 | 위키 버전 복원 | `POST /api/wiki/{id}/versions/{vid}/restore` | 200 OK |
| W-007 | 위키 댓글 조회 | `GET /api/wiki/{id}/comments` | 200 OK, 댓글 목록 반환 |
| W-008 | 위키 댓글 생성 | `POST /api/wiki/{id}/comments` | 201 Created |
| W-009 | 위키 댓글 수정 | `PUT /api/wiki/{id}/comments/{cid}` | 200 OK |
| W-010 | 위키 댓글 삭제 | `DELETE /api/wiki/{id}/comments/{cid}` | 200 OK |

### 2.2 게시판(Posts) 기능

| P-010 | 댓글 삭제 | `DELETE /api/posts/comments/{cid}` | 200 OK |

## 3. 테스트 시나리오

### 3.1 위키 테스트 시나리오

1. **기본 CRUD 테스트**
   - 테스트 프로젝트 생성/조회
   - 새 위키 페이지 생성
   - 생성된 위키 페이지 조회
   - 위키 페이지 내용 수정
   - 수정된 내용 확인
   - 위키 페이지 삭제
   - 삭제 확인

2. **버전 관리 테스트**
   - 위키 페이지 생성 후 수정 (버전 1 생성)
   - 다시 수정 (버전 2 생성)
   - 버전 이력 조회 (총 2개 버전 존재)
   - 이전 버전으로 복원
   - 복원된 내용 확인

3. **댓글 테스트**
   - 위키 페이지에 댓글 작성
   - 댓글 조회
   - 댓글 수정
   - 댓글 삭제

### 3.2 게시판 테스트 시나리오

1. **기본 CRUD 테스트**
   - 새 게시글 작성 (일반 카테고리)
   - 게시글 목록 조회
   - 게시글 상세 조회
   - 게시글 수정
   - 게시글 삭제
   - 삭제 확인

2. **카테고리별 테스트**
   - 공지사항 카테고리 게시글 작성 (admin 권한 필요)
   - 자료실 카테고리 게시글 작성 (admin 권한 필요)
   - 일반 사용자의 카테고리 제한 확인

3. **댓글 테스트**
   - 게시글에 댓글 작성
   - 댓글 조회
   - 댓글 수정
   - 댓글 삭제

## 4. 검증 기준

### 4.1 성공 기준
- 모든 API 엔드포인트가 올바른 HTTP 상태 코드 반환
- 생성된 리소스가 DB에 정상 저장
- 수정/삭제가 정상적으로 반영
- 권한 검증이 정상적으로 동작
- 버전 관리가 정상적으로 동작

### 4.2 실패 기준
- 500 Internal Server Error 발생
- 권한 없는 사용자의 접근 허용
- 데이터 무결성 위반
- 예외 처리 미흡
